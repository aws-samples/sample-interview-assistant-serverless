## Question

Compare SQL and NoSQL database systems and describe scenarios where each is most appropriate.

## Instructions

Evaluate the candidate's comprehension of data storage technologies, architectural trade-offs, and selection criteria. Focus on:

- Articulate explanation of core distinctions
- Grasp of ACID versus BASE characteristics
- Familiarity with particular database categories and application scenarios
- Practical background with database technology selection
- Recognition of contemporary hybrid solutions

## Evaluation Criteria

Assess the candidate based on:

- Articulates primary distinctions (structure definition, data consistency, horizontal growth)
- Addresses ACID guarantees and their significance
- Cites concrete examples of each database category
- Identifies suitable scenarios for SQL adoption
- Identifies suitable scenarios for NoSQL adoption
- Acknowledges compromises and decision factors
- Examines throughput and expansion attributes

## Expected Answer

Comprehensive responses generally cover:

- SQL: rigid structure definitions, ACID compliance, sophisticated join operations, normalized relationships (PostgreSQL, MySQL)
- NoSQL: adaptable structure, eventual consistency model, distributed scaling, multiple variants (document stores, key-value stores, columnar, graph databases)
- SQL scenarios: monetary systems, intricate entity relationships, strict consistency mandates
- NoSQL scenarios: massive data volumes, schema evolution requirements, distributed architecture demands, optimized query patterns
- Compromises: data consistency versus system availability (CAP theorem), query expressiveness versus execution speed
- Contemporary solutions: NewSQL architectures, polyglot persistence strategies

## Time

10 minutes
