## Question

Implement a function that identifies the first unique character in a given string.
Open a web-based coding editor such as https://www.online-python.com/ or https://www.programiz.com/python-programming/online-compiler/ and start with the implementation.

## Instructions

Assess the candidate's programming proficiency, problem-solving methodology, and optimization capabilities. Focus on:

- Selection of appropriate data structures (dictionary, character array)
- Runtime and memory complexity evaluation
- Boundary condition management (null input, strings with only duplicates)
- Code readability and formatting standards
- Capability to articulate their strategy prior to implementation

## Evaluation Criteria

Assess the candidate based on:

- Delivers a functional implementation
- Discusses runtime complexity (targeting O(n) performance)
- Discusses memory utilization
- Manages boundary conditions correctly
- Produces well-structured, maintainable code
- Explores different solution approaches
- Validates the implementation using test cases

## Expected Answer

Comprehensive responses generally cover:

- Dual-iteration approach leveraging a frequency map for character counting
- Single-iteration enhancement when applicable
- Runtime complexity: O(n), Memory complexity: O(k) where k represents alphabet size
- Boundary condition treatment: returning null/-1 for empty inputs or when no unique character exists
- Test case: "leetcode" → "l", "aabbcc" → null

## Time

15 minutes
